Pedidos ao LLM

Como a aplicação e o LLM trocam trabalho: pedidos em pastas, respondidos no repositório ou na aplicação web.

A aplicação nunca chama um LLM. Cada tarefa que precisa de um torna-se um pedido: uma pasta com o prompt completo. O pedido é respondido de uma de duas formas, com o mesmo resultado:

  1. No repositório. O LLM (por exemplo, o Claude Code a trabalhar neste repositório) lê prompt.md, escreve resposta.json na mesma pasta e faz commit. Depois de git pull, a aplicação mostra o pedido como respondido.
  2. Na aplicação web. Copia-se o prompt para qualquer LLM e cola-se a resposta na página do pedido.

Registar confirma a forma da resposta e aplica-a. Se falhar, nada é gravado, o pedido fica rejeitado com o motivo em resultado.json e pode ser respondido de novo.
