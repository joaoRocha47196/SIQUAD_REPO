ecv/5_views/catalog.py

The catalogue of views that exist for a graph.

The views are not stored anywhere: they are derived from the graph. Per HLM: the model view, the
view with rules, the projections and the gaps; per SM and USM: the specific model view; per property
restricted by at least 'decisaoMinimoRIR' RIR: the decision view; per discriminating factor: the
dependency analysis and the impact; per profile: the static selection; per example instance whose
profile exists: the validation result; per rule: its card.

Each entry is a ViewEntry: the page name (also the file name in the static site), the ViewModel and
its parameters. The web application builds the ViewModel of an entry only when it is requested.

ecv/5_views/viewmodels/model.py

ViewModel 'modelo': the view of a model (HLM, SM or USM), with or without its rules.

It is the base of three views:
  - HLM model view             (hlm_<HLM>):   tree + structure table, link to the projections;
  - model view with rules      (regras_<HLM>): the same table with the rules column and the groupings;
  - specific model view        (sm_<SM>, usm_<USM>): who uses it, tree to the leaves, table with rules.

Graph: (model)-COMPOSTO_POR*->(SM|USM)-CONTEM->(Propriedade); (Regra)-ASSOCIADA_A->(node);
Regra -RESTRITA_POR-> Restricao -RESTRINGE|CHAMA->; Regra -CONDICIONADA_POR-> Condicao -TERMO|CHAMA->;
upwards, COMPOSTO_POR backwards to the HLMs; Projecao -PROJETA-> HLM.

ecv/5_views/viewmodels/rule.py

ViewModel 'regra': the full card of a rule and its subgraph (thesis, figures 'Ligações de cada tipo
de regra' and 'A regra RIR-TEMP-REFRIG-CELSIUS no grafo').

The subgraph has two parts, drawn separately:
  - the rule subgraph (horizontal): Regra -> Restricao / CondicaoAplicabilidade -> Propriedade, Funcao -> ContextoExterno;
  - the model subgraph (vertical): each property (or model) involved -> the model that holds it -> ... -> every HLM.
Nothing is left out: every link and all the text of each element.
