ecv/2_amendments/__init__.py

2 · Amendments: changes to the declarations of a domain, as operations of a closed vocabulary.

Receives: operations ({"op": ..., fields}), from an LLM response (steps B to F, change requests), a file,
the web form or a CSV of known mappings.
Needs: the declarations, reservoir and mapping of the domain.
Produces: the declarations changed consistently (a shared model changes in every declaration; renaming
rewrites the paths of projections, profiles, rules and mapping), with descriptions derived again.

    operations.json      the vocabulary (names, fields, description, group)
    declaration_set.py   DeclarationSet: the domain's declarations as the operations see them
    operations/          one handler per operation, by group
    engine.py            apply a batch (all or nothing)
    change_requests.py   natural language -> prompt for the LLM
    csv_rules.py         table of known mappings -> RIR operations

ecv/2_amendments/csv_rules.py

Rules from a table: a CSV of known mappings becomes one RIR per row (operations 'adicionar_regra').

Typical case: the postal code that each parish of a city admits. The table

    pais;localidade;freguesia;codigoPostal
    PT;LISBOA;AJUDA;^(1300|1349)-[0-9]{3}$
    PT;LISBOA;ALCANTARA;^(1300|1350)-[0-9]{3}$

with target column 'codigoPostal' and operator PATTERN becomes, for each row, the RIR

    Se Morada.pais = PT e Morada.localidade = LISBOA e Morada.freguesia = AJUDA
    → Morada.codigoPostal segue o padrão ^(1300|1349)-[0-9]{3}$

Every column except the target (and the optional 'mensagem' and 'id' columns) is a condition term
(EQUALS). The column names are paths relative to the model where the rules live. Values that look
like numbers or booleans are typed. With RANGE, the target cell is 'minimum..maximum'; with IN, a list
separated by '|'.

ecv/2_amendments/declaration_set.py

The set of declarations of a domain, as the operations see it.

The declarations of a domain (one per HLM) live in dominios/<d>/declaracoes/. A shared model exists,
identical, in every declaration that uses it; so an operation on a model applies to every declaration
that contains it, and composing a model into a declaration that does not have it yet copies it (with
the submodels, functions and contexts it depends on). A model, function or context created without a
declaration stays in the domain's reservoir (reservatorio.json) until something composes or calls it.

ecv/2_amendments/engine.py

Applying a batch of operations to the declarations of a domain.

The batch is all or nothing: the operations run on the DeclarationSet in order; the first one that
fails raises AmendmentError (with its position) and the caller does not save. After the batch, the
functions and contexts the rules use are copied where needed, the sections are put in order and
every rule description is derived again.

ecv/2_amendments/guides.py

Guides for the operations: what has to be chosen for each operation and the operation already filled in.

For every operation of the vocabulary, SELECTORS says which existing entities the person picks (a model, one
of its properties, a rule, a projection, ...); `prefill(ds, op, selection)` returns the operation with the
fields filled from the declarations: the current values to change, the paths of a HLM for a projection, the
JSON of a rule to replace. `options(ds, selector, selection)` lists what can be picked.

Selections use plain strings: modelo 'USM:Morada', propriedade 'codigoPostal', regra 'RP-CP', hlm 'Fatura',
projecao, perfil, funcao, contexto (names) and filho 'SM:Linhas' (a composition of the chosen model).

ecv/2_amendments/operations/__init__.py

The closed vocabulary of operations on the declarations of a domain (operations.json).

Each operation is a JSON object {"op": "<name>", ...fields}. The name and the fields are part of the
vocabulary given to the LLM (Portuguese, like the declarations); each module of this package
implements one group of operations and registers each handler under its name:

    @operation("mover_propriedade")
    def move_property(ds, op, step=None) -> str      # a short description of what was done
