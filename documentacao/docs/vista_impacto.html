Impacto de uma alteração

Tudo o que é afetado se uma propriedade mudar (nome, valores plausíveis ou posição): as regras em que é alvo, termo, argumento de uma função ou onde vive, as projeções que a usam e os perfis que a fixam.

Navegação

ViewModel impacto

Pergunta: Que regras, projeções e perfis são afetados se a propriedade mudar?
Parâmetros: propriedade
Percurso no grafo: Propriedade <-RESTRINGE|TERMO|LE|ASSOCIADA_A- ... Regra; <-OBRIGATORIA|PERMITIDA- Projecao; <-FIXA- Perfil.

impacto: Impacto de uma alteração

  • Pergunta. Que regras, projeções e perfis são afetados se a propriedade mudar (nome, valores plausíveis, posição)?
  • Tese. Figura "Regras afetadas por uma alteração de tipoDispositivo" (problema P4, custo de propagação).
  • Parâmetros. propriedade.
  • Operação. Reunião de quatro percursos:
    • (p)<-[:RESTRINGE]-()<-[:RESTRITA_POR]-(regra) (alvo);
    • (p)<-[:TERMO]-()<-[:CONDICIONADA_POR]-(regra) (termo);
    • (p)<-[:LE]-(Funcao) (argumento, com a regra na aresta);
    • (p)<-[:ASSOCIADA_A]-(regra) (vive na propriedade).

Depois, (p)<-[:OBRIGATORIA|PERMITIDA]-(Projecao) e (p)<-[:FIXA]-(Perfil).

  • JSON. regras[] {id, tipo, descricao, papeis[]}, contagem {RP, RIR, RIC}, projecoes[] {projecao, tipo, caminho}, perfis[] {perfil, caminho, valor}.
  • Cypher. impacto.cypher.

Consulta Cypher equivalente (impacto.cypher)

// ViewModel 'impacto' — regras, projeções e perfis afetados por uma alteração da propriedade.
// Parâmetros: $propriedade (chave, ex.: "SM:Identificacao.tipoDispositivo").

// 1. Regras, com o papel da propriedade em cada uma
CALL () {
  MATCH (p:Propriedade {chave: $propriedade})<-[:RESTRINGE]-(:Restricao)<-[:RESTRITA_POR]-(r:Regra)
  RETURN r.id AS regra, 'alvo da restrição' AS papel
  UNION
  MATCH (p:Propriedade {chave: $propriedade})<-[:TERMO]-(:CondicaoAplicabilidade)<-[:CONDICIONADA_POR]-(r:Regra)
  RETURN r.id AS regra, 'termo da condição' AS papel
  UNION
  MATCH (p:Propriedade {chave: $propriedade})<-[le:LE]-(f:Funcao)
  RETURN le.regra AS regra, 'argumento de ' + f.nome AS papel
  UNION
  MATCH (p:Propriedade {chave: $propriedade})<-[:ASSOCIADA_A]-(r:Regra)
  RETURN r.id AS regra, 'vive na propriedade' AS papel
}
RETURN regra, collect(papel) AS papeis ORDER BY regra;

// 2. Projeções
MATCH (p:Propriedade {chave: $propriedade})<-[o:OBRIGATORIA|PERMITIDA]-(pj:Projecao)
RETURN pj.nome AS projecao, type(o) AS tipo, o.caminho AS caminho ORDER BY projecao, caminho;

// 3. Perfis
MATCH (p:Propriedade {chave: $propriedade})<-[f:FIXA]-(pf:Perfil)
RETURN pf.nome AS perfil, f.caminho AS caminho, f.valor AS valor;
