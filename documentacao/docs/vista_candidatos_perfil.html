candidatos_perfil: O que fixar num perfil

  • Pergunta. Que propriedades se podem fixar num perfil para validar estas?
  • Tese. Tabela "Pesquisa das propriedades usadas na aplicabilidade das regras sobre valor e unidadeMedida".
  • Parâmetros. alvos (lista de chaves).
  • Operação. (alvo)<-[:RESTRINGE]-()<-[:RESTRITA_POR]-(RIR)-[:CONDICIONADA_POR]->()-[:TERMO]->(p), mais os argumentos das funções nos termos.
  • JSON. linhas[] {alvo, nome, regras[], propriedades[]}, candidatas[].
  • Cypher. candidatos_perfil.cypher.

Consulta Cypher equivalente (candidatos_perfil.cypher)

// ViewModel 'candidatos_perfil' — propriedades usadas nas condições das RIR que restringem as propriedades dadas.
// Parâmetros: $alvos (lista de chaves, ex.: ["USM:Medicao.valor", "USM:Medicao.unidadeMedida"]).
UNWIND $alvos AS chave
MATCH (a:Propriedade {chave: chave})<-[:RESTRINGE]-(:Restricao)<-[:RESTRITA_POR]-(r:RIR)
      -[:CONDICIONADA_POR]->(:CondicaoAplicabilidade)-[:TERMO]->(d:Propriedade)
RETURN a.nome AS alvo, collect(DISTINCT r.id) AS regras, collect(DISTINCT d.nome) AS propriedades;
