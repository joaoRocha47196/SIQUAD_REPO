Ficha de uma regra

Tudo o que uma regra declara e todas as suas ligações, sem omissões: cada elemento (restrição, condição e termos, funções, contextos externos, propriedades) com a sua informação completa, e o subgrafo em duas partes: o da regra, na horizontal, e o dos modelos, na vertical, desde cada propriedade envolvida até ao modelo que a contém e a todos os HLM que a usam.

CampoValor
Páginaregra_<ID>
ViewModelregra
Para que serveCompreender e rever uma regra por completo; ver em que HLM ela tem efeito.
Exemploregra_RIR-TEMP-REFRIG-CELSIUS.html (estática) · na aplicação: /vistas/regra_RIR-TEMP-REFRIG-CELSIUS.html

Dados que agrega

  • a regra: tipo, natureza, descrição, onde vive, mensagem, conclusão, notas
  • a restrição: forma, operador, valor, alvo (com descrição) ou a função chamada (descrição, parâmetros, argumentos, contextos)
  • a condição: cada termo com a propriedade (e descrição), o operador e o valor ou o contexto externo
  • a cadeia de modelos: propriedade → USM/SM → … → HLM, para todas as propriedades envolvidas

Como usar

  • Passar o rato sobre um nó do subgrafo para ver a descrição.
  • A tabela de ligações dá o texto completo de cada aresta.
  • Clicar nos modelos e propriedades para as vistas respetivas.
  • Subgrafo em duas partes: a regra (horizontal) e os modelos (vertical, até aos HLM).

Navegação

ViewModel regra

Pergunta: O que declara uma regra, a que elementos está ligada e por que modelos chega a cada HLM?
Parâmetros: id
Percurso no grafo: Regra -ASSOCIADA_A->, -RESTRITA_POR-> Restricao (-RESTRINGE->, -CHAMA-> Funcao -LE->, -DEPENDE_DE->), -CONDICIONADA_POR-> Condicao (-TERMO->, -CHAMA->, -DEPENDE_DE->); de cada propriedade envolvida: <-CONTEM- modelo <-COMPOSTO_POR- … HLM.

regra: Ficha de uma regra

  • Pergunta. O que declara uma regra, a que elementos está ligada e por que modelos chega a cada HLM?
  • Tese. Figuras "Ligações de cada tipo de regra no grafo" e "A regra RIR-TEMP-REFRIG-CELSIUS no grafo".
  • Parâmetros. id.
  • Operação sobre o grafo.
    1. A regra e -[:ASSOCIADA_A]-> (onde vive).
    2. -[:RESTRITA_POR]->(Restricao): -[:RESTRINGE]->(Propriedade) ou -[:CHAMA]->(Funcao)-[:LE {regra}]->, -[:DEPENDE_DE]->(ContextoExterno).
    3. -[:CONDICIONADA_POR]->(Condicao): -[:TERMO]->, -[:CHAMA]->, -[:DEPENDE_DE]->.
    4. De cada propriedade (ou modelo) envolvida: <-[:CONTEM]-(dono)<-[:COMPOSTO_POR*]- até todos os HLM.
  • JSON. regra (ficha), restricao (com alvo e, numa função, funcao com parâmetros e contextos), condicao (termos[] com alvo, contextoInfo ou funcao), viveEm (com os HLM onde tem efeito), subgrafoRegra = {nos[], arestas[]}, subgrafoModelos = {nos[], arestas[]}.
  • Cypher. regra.cypher (ficha, subgrafo da regra, cadeia dos modelos).

Consulta Cypher equivalente (regra.cypher)

// ViewModel 'regra' — ficha de uma regra, o subgrafo da regra e a cadeia dos modelos até aos HLM.
// Parâmetros: $id (ex.: "RIR-TEMP-REFRIG-CELSIUS").

// 1. Ficha
MATCH (r:Regra {id: $id})-[:ASSOCIADA_A]->(vive)
OPTIONAL MATCH (r)-[:RESTRITA_POR]->(rs:Restricao)
OPTIONAL MATCH (rs)-[rg:RESTRINGE]->(alvo:Propriedade)
OPTIONAL MATCH (r)-[:CONDICIONADA_POR]->(c:CondicaoAplicabilidade)
RETURN r.id AS id, [l IN labels(r) WHERE l <> 'Regra'][0] AS tipo, r.descricao AS descricao,
       coalesce(vive.chave, vive.nome) AS viveEm, c.descricao AS condicao, rs.descricao AS restricao,
       alvo.chave AS alvo, alvo.descricao AS descricaoAlvo, coalesce(rs.mensagem, r.mensagem) AS mensagem,
       r.contextosExternos AS contextos;

// 2. Subgrafo da regra (para ver no Neo4j Browser em modo grafo)
MATCH (r:Regra {id: $id})
OPTIONAL MATCH p1 = (r)-[:ASSOCIADA_A|RESTRITA_POR|CONDICIONADA_POR]->()
OPTIONAL MATCH p2 = (r)-[:RESTRITA_POR|CONDICIONADA_POR]->()-[:RESTRINGE|TERMO|CHAMA|DEPENDE_DE]->()
OPTIONAL MATCH p3 = (r)-[:RESTRITA_POR|CONDICIONADA_POR]->()-[:CHAMA]->()-[le:LE]->()
WHERE le.regra = $id
OPTIONAL MATCH p4 = (r)-[:RESTRITA_POR|CONDICIONADA_POR]->()-[:CHAMA]->()-[:DEPENDE_DE]->()
RETURN p1, p2, p3, p4;

// 3. Cadeia dos modelos: de cada propriedade envolvida (onde vive, alvo, termos, argumentos) até todos os HLM
MATCH (r:Regra {id: $id})
OPTIONAL MATCH (r)-[:ASSOCIADA_A]->(a)
OPTIONAL MATCH (r)-[:RESTRITA_POR|CONDICIONADA_POR]->()-[:RESTRINGE|TERMO]->(b)
OPTIONAL MATCH (r)-[:RESTRITA_POR|CONDICIONADA_POR]->()-[:CHAMA]->()-[le:LE]->(c) WHERE le.regra = $id
WITH collect(DISTINCT a) + collect(DISTINCT b) + collect(DISTINCT c) AS envolvidos
UNWIND envolvidos AS x
MATCH cadeia = (h:HLM)-[:COMPOSTO_POR*0..]->(m)-[:CONTEM*0..1]->(x)
RETURN cadeia;
